# CL Developer — Portafolio Personal

Portafolio web profesional de **César Alejandro** ([@clamper2006](https://github.com/clamper2006)), desarrollado con diseño editorial moderno, experiencia bilingüe (ES / EN), animación orbital interactiva y una integración oficial y fiel a la marca **Amplify**.

🌐 **Sitio Web:** [https://clamper2006.github.io/CL-dev-Portafolio/](https://clamper2006.github.io/CL-dev-Portafolio/)

---

## 🎨 Características del Proyecto
- **Diseño Editorial & Moderno:** Inspirado en principios de diseño de productos de alta gama (Apple, editoriales contemporáneos).
- **Animación Orbital 3D Liviana:** Construida enteramente con CSS 3D transforms y SVG (sin dependencias pesadas como Three.js).
- **Bilingüe (ES / EN):** Sistema de traducción dinámico en el cliente sin recargas de página.
- **Sección Especial Amplify:** Integración con la paleta oficial (#3BF087 verde neón, #0A0A0C fondo profundo) y activos autorizados de la agencia.
- **100% Responsivo:** Optimizado para pantallas móviles (320px - 430px), tablets y monitores ultrawide.
- **Accesibilidad y Rendimiento:** Compatible con `prefers-reduced-motion`, navegación por teclado y semántica HTML5.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5 Semántico**
- **CSS3 Moderno** (Custom Properties, Grid, Flexbox, Fluid Clamp, 3D Transforms)
- **JavaScript Moderno (ES6+)** (Vanilla, modular y ligero)
- **Google Fonts** (Playfair Display, Plus Jakarta Sans, Space Grotesk, Space Mono)

## 🚀 Despliegue en GitHub Pages
Para desplegar el portafolio en GitHub Pages:
1. En GitHub, ve a **Settings** > **Pages**.
2. En **Build and deployment**, selecciona la rama `main` y la carpeta `/ (root)`.
3. Haz clic en **Save**. En 1-2 minutos tu portafolio estará disponible en vivo.
